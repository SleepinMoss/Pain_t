# What in the world...
So, a few months ago i started to really like digital art. Then, i had the delusional idea to make my own drawing app. It was supposed to be a quick little project, yea it doesn't. Instead it turned into 480 lines of code, making me question my whole life decision. That is why Pain_t sounds like a really good name!
Also, I made the icon in Pain_t itself!

# Features
1. Brush
2. Eraser
3. Color Picker
4. Undo
5. Redo
6. Brush Stabilizer
7. HSV Color
8. Export as PNG
9. Import PNG, JPEG, and pain_t JSON file
10. Save as JSON, so you can access stroke history enabling undo and redo

# Keybind
- B = Brush
- E = Eraser
- C = Color Picker
- A = Decrease Brush Size
- D = Increase Brush Size
- Ctrl + z = Undo
- Ctrl + y = Redo

# How to Install
Look at release tab, download according to your operating system, extract, have fun! Or should i say pain.

For Linux user:
After extracting the zip file, you need to make it an executable. Open your terminal and go to the directory Pain_t located. Then, make it an executable!
cd path/to/file
chmod +x pain_t
